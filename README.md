# TSCC (T S Construction Company) — Website

This repository contains the TSCC marketing website / portfolio built with Vite + React + TypeScript.

## Local development

Prerequisites: Node.js + npm.

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

## Tech stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
